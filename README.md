# «КОЧ! — Найди братана в бане»

> **Как играть:** откройте ссылку GitHub Pages из раздела **About** этого репозитория — игра запустится прямо в браузере. Найдите братана в парной, и он крикнет «КОЧ!».

Мини-игра запускается прямо в браузере: ничего устанавливать не нужно.

## Текст для описания репозитория на GitHub

Скопируйте этот текст в поле **About → Description**:

> 🧖 «КОЧ!» — браузерная игра: найди братана в бане. Чтобы начать, открой ссылку сайта справа в разделе About.

После включения GitHub Pages добавьте выданную GitHub ссылку в поле **About → Website**. Тогда посетитель сможет зайти в репозиторий и сразу нажать ссылку **Website**, чтобы начать играть.

## Быстрый запуск

Откройте файл [`index.html`](./index.html) двойным щелчком или запустите в папке проекта:

```bash
python3 -m http.server 8080
```

После этого перейдите по ссылке **http://localhost:8080** и начинайте искать братана.

## Как получить публичную ссылку через GitHub Pages

В проект добавлен workflow для GitHub Pages. После публикации репозитория на GitHub:

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **GitHub Actions**.
3. Сделайте push в ветку `main` (или запустите workflow **Deploy game to GitHub Pages** вручную в разделе Actions).
4. GitHub покажет готовую публичную ссылку в результате выполнения workflow. Обычно она выглядит так: `https://<ваш-логин>.github.io/<имя-репозитория>/`.
5. Скопируйте её в **About → Website** — это будет кнопка входа в игру на странице репозитория.

Эта ссылка откроет игру сразу в браузере.
